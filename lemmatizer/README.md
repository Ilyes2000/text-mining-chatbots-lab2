## Overview

This project focuses on the implementation and evaluation of French lemmatization methods as part of Lab 2 of the Text Mining and Chatbots course.

The objective is to predict the lemma (canonical form) of a word, optionally using its part-of-speech (PoS) tag, and to compare multiple approaches on both in-domain and out-of-domain datasets.

Three lemmatization strategies are implemented and evaluated:

Dictionary-based lemmatization

Machine learning–based lemmatization (character-level)
